# 产品定位与能力边界

状态：设计基线

## 产品定位

**Agent Dogs 是一个以本地工作空间为核心的个人工作 Agent。**它以用户目标为驱动，理解授权范围内的文件与项目上下文，协助用户完成从信息获取到内容产出的工作。

## 产品功能

Agent Dogs 支持用自然语言查找和理解文件、分析数据、撰写内容、编写与修改代码，以及管理文件。系统能够结合相关资料执行多步骤任务，并呈现结果、依据和产物。

## 能力边界

- 仅在用户授权的资源范围内读取与操作；工作空间是默认的本地上下文边界。
- 涉及文件修改或其他有影响的操作时，展示拟执行内容，允许用户介入，并记录实际执行结果。
- 面向用户主动发起的工作任务；未来可接入网页研究、跨应用协作和电脑操作，但这些能力不构成当前实现的前置条件。
- 是否使用计划或专门 Agent 由任务复杂度决定。用户关注的是任务结果、来源与可控性，不需要理解内部 Agent 分工。

## 产品验收原则

能找到正确材料并指出依据；能交付可使用的内容或产物；能说明读取范围、计划变更和已执行操作；失败、取消或重启后状态明确，不把未知执行结果误报为成功。
