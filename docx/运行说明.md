# 前后端运行说明

本文档说明 Agent Dogs 在本地开发、前后端联调、调试面板和打包后的运行方式。

## 项目组成

- 后端：FastAPI 服务，入口为 `agent.api.app:app`，默认地址 `http://127.0.0.1:8000`。
- 前端：Vite + React 应用，目录为 `GUI/`，默认地址 `http://127.0.0.1:5173`。
- 模型配置：默认读取 `config/llm.yaml`。
- workspace：文件工具默认只访问 `workspace/`。

开发时通常同时启动后端和前端。前端开发服务器会把 `/api` 请求代理到后端。

## 后端运行

安装依赖：

```powershell
pip install -r requirements.txt
```

启动 FastAPI：

```powershell
python -m uvicorn agent.api.app:app --host 127.0.0.1 --port 8000 --reload --reload-dir agent --reload-dir config
```

开发模式建议只监听 `agent/` 和 `config/`。CodeAgent 的临时执行脚本已改为非 `.py` 文件，避免触发 Uvicorn 热重载；如果后续 artifacts 里出现其他会触发 reload 的开发产物，仍建议使用限定监听目录的启动方式。

后端地址：

```text
http://127.0.0.1:8000
```

API 前缀：

```text
/api/v1
```

健康检查：

```powershell
curl http://127.0.0.1:8000/api/v1/health
```

正常返回：

```json
{"status":"ok"}
```

## CLI 运行

交互模式：

```powershell
python -m agent
```

单次消息：

```powershell
python -m agent -m "你好"
```

CLI 与 API 使用同一套模型配置。

## 前端运行

进入前端目录：

```powershell
cd GUI
```

安装依赖：

```powershell
npm install
```

启动开发服务器：

```powershell
npm run dev
```

访问：

```text
http://127.0.0.1:5173
```

`GUI/vite.config.js` 会把 `/api` 代理到：

```text
http://127.0.0.1:8000
```

请求链路：

```text
Browser http://127.0.0.1:5173
  -> Vite dev server
  -> /api proxy
  -> FastAPI http://127.0.0.1:8000/api/v1
```

## API 根路径配置

前端 API 封装位于：

```text
GUI/src/api.js
```

默认 API 根路径：

```text
/api/v1
```

如需覆盖：

```powershell
$env:VITE_API_ROOT = "http://127.0.0.1:8000/api/v1"
```

## Agent 调试面板

前端支持 Agent 信息流调试面板。默认关闭。

环境变量开启：

```powershell
$env:VITE_AGENT_DEBUG_PANEL = "true"
npm run dev
```

浏览器 localStorage 覆盖：

```javascript
localStorage.setItem("agentDebugPanel", "true")
localStorage.setItem("agentDebugPanel", "false")
```

前端侧边栏也有“调试信息”开关，状态会同步到 `localStorage.agentDebugPanel`。

开启后，每条 assistant 消息下方会显示“调试信息”折叠面板，包含：

- 主 Agent：输入、任务分析、`TaskBrief`、route、complexity、最终汇总输出。
- 子 Agent：使用了哪个 Agent、能力说明、输入、输出、状态、错误。
- 工具调用：工具名、payload、状态、错误。
- 最终输出。
- 原始 JSON。

后端始终可以返回调试 metadata，前端只控制是否展示。

## 模型配置

默认配置文件：

```text
config/llm.yaml
```

也可以通过环境变量指定：

```powershell
$env:AGENT_LLM_CONFIG = "D:\path\to\llm.yaml"
```

Provider 类型：

- `api`: OpenAI-compatible API。
- `ollama`: 本地 Ollama。
- `builtin`: 项目内置 GGUF 模型。

默认模型由 `default_model` 决定。模型调用不会在 Provider 之间自动 fallback。

建议使用环境变量存放 API Key：

```powershell
$env:OPENAI_API_KEY = "你的 API Key"
```

## 联网搜索配置

`web_search` 默认关闭。配置位于 `config/llm.yaml`：

```yaml
search:
  enabled: false
  provider: duckduckgo
  max_results: 5
  fetch_pages: 3
  timeout: 10
  user_agent: AgentDogs/0.1
```

临时启用：

```powershell
$env:AGENT_WEB_SEARCH_ENABLED = "1"
```

启用后，“今天北京的天气怎么样”“搜索今年足球比赛信息”等需要实时外部信息的问题会由 MainAgent 委派给 `SearchAgent`，再调用 `web_search`。MainAgent 会对搜索结果做最终汇总，原始搜索结果保留在调试面板。

## CodeAgent 沙箱配置

CodeAgent 第一阶段使用 OpenSandbox 沙箱执行 Python。默认关闭：

```yaml
code_execution:
  enabled: false
  backend: opensandbox
  image: python:3.11-slim
  timeout_seconds: 20
  memory_limit: 512m
  cpu_limit: 1
  network_enabled: false
  workspace_readonly: true
  artifacts_dir: runtime/artifacts
  max_output_chars: 12000
  allow_user_script_execution: false
  max_artifacts: 20
  max_artifact_bytes: 26214400
  opensandbox:
    domain: ${OPENSANDBOX_DOMAIN:-127.0.0.1:8080}
    protocol: ${OPENSANDBOX_PROTOCOL:-http}
    api_key: ${OPENSANDBOX_API_KEY:-}
    request_timeout_seconds: 60
  dependency_install:
    enabled: false
    timeout_seconds: 120
    allowed_packages:
      - pandas
      - numpy
      - openpyxl
      - matplotlib
      - seaborn
      - scipy
      - scikit-learn
```

启用方式：

```yaml
code_execution:
  enabled: true
  allow_user_script_execution: true
  dependency_install:
    enabled: true
```

安全策略：

- OpenSandbox Server 不可用时返回明确错误。
- 不回退到宿主机 Python。
- workspace 只读挂载。
- artifacts 输出到 `runtime/artifacts/<run_id>/`。
- 默认无网络；只有依赖安装启用且任务需要安装依赖时才打开 OpenSandbox network。
- 运行时依赖安装受 `dependency_install.allowed_packages` 限制。
- 用户脚本执行需要显式启用 `allow_user_script_execution`。

artifact 下载接口：

```text
GET /api/v1/artifacts/{run_id}/{filename}
```

## TaskAgent 与二次确认

复杂任务在前端确认计划后，会进入 `TaskAgent` 第一阶段执行。这里的“计划确认”只表示用户同意开始执行计划，不等于允许直接写 workspace。

TaskAgent 当前会自动执行或委派的低风险步骤：

- 文件读取和文件搜索：委派给 `FileAgent`。
- workspace/联网搜索：委派给 `SearchAgent`。
- 数据分析、图表生成、代码结构分析：委派给 `CodeAgent`，产物写入 `runtime/artifacts/<run_id>/`。
- 方法选择、图表类型选择等判断步骤：记录为 `manual_review`，作为上下文保留。

需要二次确认的高风险步骤：

- 创建 workspace 目录。
- 写入、修改、删除、重命名 workspace 文件。
- 移动或复制文件。
- 把 CodeAgent artifacts 发布到 workspace 指定目录。

这些步骤会返回 `waiting_confirmation`，并在 `task_steps[].confirmation_payload` 和 `pending_confirmations` 中记录待确认动作。当前已注册但默认不会自动调用的高风险工具：

- `create_directory`: 在 workspace 内创建目录。
- `publish_artifact`: 把 `runtime/artifacts` 中的产物复制到 workspace。

示例：用户要求“分析 `02.xlsx` 并将图表存放到 `02_analys` 文件夹”时，TaskAgent 会先让 CodeAgent 在 OpenSandbox 沙箱中分析和生成 artifact，然后把“创建 `02_analys`”和“发布 artifact 到 `02_analys`”标记为等待二次确认。

## 打包运行

前端构建：

```powershell
cd GUI
npm run build
```

输出目录：

```text
GUI/dist
```

如果 `GUI/dist` 存在，后端会静态托管构建产物：

- `/assets` -> `GUI/dist/assets`
- 其他前端路径回退到 `GUI/dist/index.html`

因此打包后可以只启动后端：

```powershell
python -m uvicorn agent.api.app:app --host 127.0.0.1 --port 8000
```

访问：

```text
http://127.0.0.1:8000
```

## 常见问题

### 前端显示“无法连接后端”

检查：

- 后端是否在 `127.0.0.1:8000` 运行。
- 前端是否通过 Vite dev server 访问，而不是直接打开 HTML。
- `VITE_API_ROOT` 是否配置错误。
- 后端日志是否有 500 或 503。

### 模型调用报 `tool_calls: empty array`

这是历史上把应用调试 metadata 写入 LangChain `additional_kwargs` 后污染模型协议导致的问题。当前实现已经把应用 metadata 放到 `response_metadata["agent_dogs"]`，并在模型调用前清洗历史消息。

### LangGraph checkpoint warning

当前仍可能看到类似“serializing/deserializing unregistered type”的 warning，因为 checkpoint 中还存在部分 Python/Pydantic 对象。短期不影响测试和运行；后续切换持久化 checkpoint 前建议把 graph state 收敛为纯 JSON 可序列化字段。

## 后端模块拆分说明

当前 `agent/core/main_agent.py` 只保留主编排入口、LangGraph 节点和 chat/resume 流程。原先集中在 MainAgent 中的领域逻辑已经拆分到以下模块：

- `agent/core/agent_routing.py`：任务判断、路径识别、规则路由、LLM 任务解析、`TaskBrief` 构造。
- `agent/core/agent_debug.py`：`debug_trace` 和分层 `agent_flow`。
- `agent/core/agent_responses.py`：搜索、天气、CodeAgent 等结果的最终回答汇总。
- `agent/core/agent_metadata.py`：`response_metadata["agent_dogs"]`、历史消息记录和协议字段清洗。
- `agent/core/utils/prompt.py`：默认系统提示、任务解析 prompt、任务规划 prompt、SimpleChat 防幻觉提示。

如果要调整主 Agent 的提示词，优先修改 `agent/core/utils/prompt.py`；如果要调整路由规则，优先修改 `agent/core/agent_routing.py`。

推荐完整后端回归：

```powershell
python -m unittest discover -s tests -q
```
