# 前后端运行说明

本文档说明当前项目在本地开发、前后端联调以及前端打包后的运行方式。

## 项目运行总览

当前项目由后端、前端和模型配置三部分组成：

- 后端：FastAPI 服务，入口为 `agent.api.app:app`，默认运行在 `http://127.0.0.1:8000`。
- 前端：Vite + React 应用，目录为 `GUI/`，开发环境默认运行在 `http://127.0.0.1:5173`。
- 配置：模型与 Provider 配置默认读取 `config/llm.yaml`。

开发时通常需要同时启动后端和前端。前端开发服务器会把 `/api` 请求代理到后端服务，因此浏览器只需要访问前端地址。

## 后端运行方式

### 1. 安装 Python 依赖

在项目根目录执行：

```powershell
pip install -r requirements.txt
```

### 2. 启动 FastAPI 服务

在项目根目录执行：

```powershell
python -m uvicorn agent.api.app:app --host 127.0.0.1 --port 8000 --reload
```

启动后，后端服务地址为：

```text
http://127.0.0.1:8000
```

后端 API 默认前缀为：

```text
/api/v1
```

健康检查接口为：

```text
GET http://127.0.0.1:8000/api/v1/health
```

正常返回示例：

```json
{"status":"ok"}
```

### 3. 命令行模式

项目也提供 CLI 对话入口。在项目根目录执行：

```powershell
python -m agent
```

也可以发送单条消息后退出：

```powershell
python -m agent -m "你好"
```

CLI 与 API 使用同一套模型配置。

## 前端运行方式

### 1. 安装 Node 依赖

进入前端目录：

```powershell
cd GUI
npm install
```

### 2. 启动前端开发服务器

在 `GUI/` 目录执行：

```powershell
npm run dev
```

前端默认访问地址为：

```text
http://127.0.0.1:5173
```

`GUI/package.json` 中的开发命令实际执行：

```text
vite --host 127.0.0.1
```

`GUI/vite.config.js` 中固定配置开发端口为 `5173`。

## 前后端联动逻辑

前端 API 封装位于 `GUI/src/api.js`，默认 API 根路径为：

```text
/api/v1
```

如需覆盖默认 API 根路径，可以设置环境变量：

```text
VITE_API_ROOT
```

开发环境下，`GUI/vite.config.js` 将 `/api` 请求代理到：

```text
http://127.0.0.1:8000
```

因此开发联调时的请求链路为：

```text
浏览器 http://127.0.0.1:5173
  -> Vite 开发服务器
  -> /api 代理
  -> FastAPI http://127.0.0.1:8000/api/v1
```

推荐开发启动顺序：

1. 在项目根目录启动后端：

   ```powershell
   python -m uvicorn agent.api.app:app --host 127.0.0.1 --port 8000 --reload
   ```

2. 另开一个终端，进入 `GUI/` 启动前端：

   ```powershell
   cd GUI
   npm run dev
   ```

3. 在浏览器访问：

   ```text
   http://127.0.0.1:5173
   ```

## 打包后运行方式

前端打包命令需要在 `GUI/` 目录执行：

```powershell
npm run build
```

构建产物输出到：

```text
GUI/dist
```

后端启动时会检查 `GUI/dist` 是否存在。如果该目录存在，FastAPI 会静态托管前端构建产物：

- `/assets` 挂载 `GUI/dist/assets`
- 其他前端路径回退到 `GUI/dist/index.html`

因此打包后可以只启动后端：

```powershell
python -m uvicorn agent.api.app:app --host 127.0.0.1 --port 8000
```

然后访问单服务地址：

```text
http://127.0.0.1:8000
```

这种方式适合本地预览打包后的完整应用。

## 模型与配置说明

默认配置文件为：

```text
config/llm.yaml
```

也可以通过环境变量指定其他配置文件：

```powershell
$env:AGENT_LLM_CONFIG = "D:\path\to\llm.yaml"
```

当前配置支持三类 Provider：

- `api`：OpenAI 兼容 API，默认读取 `OPENAI_API_KEY` 环境变量。
- `ollama`：本地 Ollama 服务，默认地址为 `http://127.0.0.1:11434`。
- `builtin`：项目内置 GGUF 模型，默认模型文件位于 `model/MiniCPM/MiniCPM5-1B-GGUF/` 下。

默认模型由 `config/llm.yaml` 中的 `default_model` 决定。当前默认 Provider 为 `builtin`。

如需使用 OpenAI 兼容 API，可在 PowerShell 中设置：

```powershell
$env:OPENAI_API_KEY = "你的 API Key"
```

## 常用验证命令

### 后端健康检查

后端启动后执行：

```powershell
curl http://127.0.0.1:8000/api/v1/health
```

期望返回：

```json
{"status":"ok"}
```

### 后端自动测试

在项目根目录执行：

```powershell
python -m unittest discover -s tests
```

### 前端构建验证

在 `GUI/` 目录执行：

```powershell
npm run build
```

如果构建成功，会生成或更新 `GUI/dist`。
